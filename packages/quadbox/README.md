# Managed feed policy and audio

`src/policy.ts` owns the current four-total managed-feed ceiling, including pending creations, independently of account allowance. UI and worker Add/Connect use `canAddManagedFeed`; layout planning, command validation, custom-position storage and the remote share `isManagedFeedCount` and `MANAGED_FEED_COUNTS`. `src/index.ts` serializes mute-all-before-enable-one audio handoff and compensates failures. The Chrome worker owns actual tab/window/session lifecycle; this package does not compose protected streams. [Policy/audio tests](../../tests/ssot.test.ts) use synthetic ports and do not prove audible output or service capacity. See [architecture](../../docs/ARCHITECTURE.md).

`src/geometry.ts` owns logical outer-window geometry for one to four shows. Presets include Best fit, stacked rows, side-by-side columns, a grid and a larger main show on any side. Custom normalized rectangles preserve each show’s chosen position. The remote preview, full-size drawing page and worker placement use the same planner; explicit layouts report an area that is too small rather than changing orientation.
