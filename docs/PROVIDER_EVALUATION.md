# Sports data boundaries

Updated 2026-10-02. Current scope is [S2-G1 Sports from the native guide](../NEXT_TASK.md). Use existing authenticated program/channel metadata and permissions for discovery, search and validated Watch/Add. No provider provisioning or credential setup is required.

Guide titles, channels, current/next listings and observation age support browsing. They do not establish independent scores, period/clock, delays, suspension, finality or a game continuing beyond its scheduled end. Keep guide discovery separate from authoritative Sports Engine state and show missing data truthfully.

Independent score/state features remain a future separately scoped enhancement. No source is selected for activation by the current task. Earlier evaluation and locally tested work remain in the [historical run](evidence/runs/20261002-s2-l1/run.md) and [scope archive](evidence/runs/20261002-s2-guide-scope/run.md); these records do not direct current owner actions. Full Sports/beta acceptance stays open.
